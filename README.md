# daily_con · 집에서 영어 회화

하루 5쌍(10문장) 가정 생활 영어 회화를 90일 동안 연습하는 웹앱입니다.

## 학습 단계
1. **듣기**: 전체 대화를 3번 듣습니다. 처음은 천천히, 다음 2번은 보통 속도입니다.
2. **대화 듣기**: A가 묻고, 대답할 시간을 준 뒤 B가 대답합니다. 전체를 2번 반복합니다.
3. **한글 보고 말하기**: A용, B용 한글을 보고 영어로 말합니다. 각각 2번 반복합니다.
4. **직접 말하기(마이크)**: 말한 소리를 한글 발음으로 보여 주고 단어별로 피드백합니다.

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 앱 (이 파일 하나로 실행됨) |
| `src/app.html` | 화면과 동작 코드 (템플릿) |
| `data/b1.txt` ~ `b6.txt` | 회화 데이터, 15일씩 6묶음 = 90일 |
| `data/hangul.txt` | 단어별 한글 발음 사전 |
| `build.py` | 템플릿과 데이터를 합쳐 `index.html`을 만드는 스크립트 |

## 데이터 형식 (`data/b?.txt`)
```
## 한글 주제|English Topic
A 영어|A 한글|B 영어|B 한글
```
하루는 `##` 줄 하나와 대화 5줄로 이루어집니다.

## 수정 후 다시 만들기
```
python build.py
```
